# visualisation-of-classification-in-nnet
 Projekt Inżynierski - wizualizacja procesu klasyfikacji w sieci neuronowej MLP


To run this project:
1. prepare python virtual environment
	1.1. navigate to venv directory, eg. C:\Users\[UserName]\venv
	1.2. python -m venv [venv_name] (this may take a long time)
	1.3. [venv-name]\Scripts\activate.bat
	1.4. install dependencies in virtual environment:
		1.4.1. pip install -U scikit-learn
		1.4.2. pip install -U matplotlib
		1.4.3. pip install -U pandas
		If You installed Python without Tk:
		1.4.4. pip install -U tk
2. Run mainWindow.py
	E.g.:
	2.1. python -m idlelib.idle
	2.2. Navigate to project directory, open mainWindow.py and run it.
